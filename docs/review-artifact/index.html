Why this design

Controls before automation

  • 01Permission is explicit. A preflight shows engine, provider, model, reference version, tolerances and warnings before any file is processed.
  • 02Extraction is separate from approval. Completeness describes filled fields; validation and human review determine export readiness.
  • 03Exceptions stop safely. Missing identity, quantity, price, receipt or tax evidence stays held for correction.
  • 04The source stays visible. Reviewers compare the original document with editable values and provenance.
  • 05Urgency is explicit. Manual download exposes every target field but is labelled unvalidated and reserves no receipt.

API boundary

Contract at a glance

POST /api/preflightBuilds a rule plan from metadata only.
GET /api/reference-lookup/*Finds source evidence without granting approval.
POST /api/jobs/:id/draftReturns a detached DRAFT_UNVALIDATED workbook.
POST /api/jobs/:id/reviewSaves edits with optimistic revision checking.
POST /api/exports/batchAtomically exports selected ready invoices.
POST /api/chatgpt/export|importMoves owner credentials local → authenticated hosted workspace.

Security posture

Data boundaries

  • Non-GET requests require a same-origin studio header; every cloud API route requires owner authentication.
  • Uploads are bounded by type, size and page/frame limits.
  • API keys and setup tokens stay encrypted server-side and absent from state responses.
  • Reader subprocesses do not receive provider secrets.
  • Claude receives required extracted text with tools disabled and a restricted environment.
  • ChatGPT export removes the local encrypted credential and active selection before hosted import.
  • Originals, drafts, bundles and responses use no-store and restrictive browser headers.

Design choices

Decisions that shape the MVP

ChoiceWhyTrade-off
Readable-PDF fast pathPreserves native text and avoids expensive image OCR when no template matches.Native text still needs structured extraction and evidence review.
Preflight token bound to rulesMakes provider, model, references and tolerances reviewable before processing.A changed rule invalidates the plan and requires another confirmation.
Lookup separate from approvalLets operators search large real sources without silently approving a match.Conflicts require explicit selection and steward follow-up.
Manual draft separate from exportUrgent entry can continue during OCR without consuming receipts or changing the job.The receiving process must respect the prominent unvalidated label.
Move-only ChatGPT transferAvoids two hosts racing one rotating refresh token.A lost one-time bundle requires local reconnection.

  • Measure field completeness and validation holds separately
  • Record reviewer time, correction types and failure causes
